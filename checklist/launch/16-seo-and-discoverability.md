# 16. SEO & discoverability

**Priority:** Launch · **Theme:** Launch · **Checks:** 19

If search engines can't crawl it, nobody finds it.

- [ ] **Publish a `sitemap.xml`**: generated automatically and submitted to search engines.
- [ ] **Publish a `robots.txt`**: and make sure it isn't blocking everything.
- [ ] **Remove `noindex` tags**: leftovers from staging hide your whole site from Google.
- [ ] **Add canonical tags to every page**: tells search engines which URL is the real one.
- [ ] **Write a unique meta title for every page**: it's the headline in search results.
- [ ] **Write a unique meta description for every page**: it's the pitch under the headline.
- [ ] **Use one H1 per page**: it's the page's main topic for search engines and screen readers.
- [ ] **Fix heading hierarchy**: H1, then H2, then H3, with no skipped levels.
- [ ] **Add alt text to every image**: search engines read it, and so do screen readers.
- [ ] **Add schema markup**: JSON-LD for Organization, Product, Article, FAQ and so on, for rich results.
- [ ] **Add internal links between related pages**: helps crawlers and keeps readers moving.
- [ ] **Fix broken links**: they waste crawl budget and make the site look abandoned.
- [ ] **Compress images**: WebP or AVIF, correctly sized, lazy-loaded.
- [ ] **Improve Core Web Vitals**: LCP, INP and CLS are ranking signals.
- [ ] **Fix mobile responsiveness**: Google indexes the mobile version first.
- [ ] **Clean up URL slugs**: `/pricing`, not `/page?id=7`.
- [ ] **Verify Google Search Console**: and Bing Webmaster Tools, to see indexing errors and submit your sitemap.
- [ ] **Add `llms.txt`**: a plain summary of your site so AI assistants describe you correctly.
- [ ] **Build a backlink strategy**: links from reputable sites are still how you earn rank.
